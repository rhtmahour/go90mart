# 🛒 Go90 Mart - Online Grocery App (Flutter)

Go90 Mart is a modern online grocery shopping app built using Flutter. This application offers a smooth user experience for browsing, selecting, and purchasing grocery products directly from a mobile device.

## ✨ Features

### ✅ User Interface
- **Welcome Screen**: Initial branding and entry point to the app.
- **Login & Signup**: Secure authentication with Phone Number and OTP verification.
- **Home Screen**: Displays featured products and categories.

### 🛍️ Shopping Experience
- **Product Listing**: Fetches products via WooCommerce API.
- **Product Detail Page**: Detailed view of products including image, price, and description.
- **Cart Management**:
  - Add items to cart
  - Modify item quantity (increase/decrease)
  - Proceed to Checkout

### 💳 Payment Integration
- **Stripe Payment Gateway**: Secure and reliable payment handling for online orders.

### 📦 Order Placement
- After successful checkout and payment, the order is confirmed and placed within the app.

## 🔧 Technologies Used

- **Flutter** (UI framework)
- **Dart** (Programming language)
- **WooCommerce API** (Product management)
- **Firebase Authentication** (Phone number + OTP login)
- **Stripe API** (Payment processing)
